# Code of conduct

This project is a small open-source tool for developers dealing with Pakistani tax compliance. Everyone who takes part, in issues, pull requests, discussions or anywhere else connected to the project, is expected to:

- Be respectful. Disagree with ideas, not with people. No harassment, insults, discrimination or personal attacks, in any language.
- Be careful with data. Never post real taxpayer identifiers, tokens or real invoices. Use the fake values from `fixtures/`.
- Be honest about uncertainty. This tool exists because the official documentation is unclear in places; saying "I don't know" or "the spec doesn't say" is the right answer more often than not.
- Stay on topic. Tax policy debates and advice about what a business should file belong elsewhere.

Maintainers may edit, hide or remove content and block participants who break these expectations. To report a problem, use the private **Report a vulnerability** form on the Security tab for security matters, or email the maintainer listed in `package.json` for conduct matters. Reports are handled in confidence.
